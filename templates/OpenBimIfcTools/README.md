# OpenBIM IFC Tools & Python Automation

Automated scripts for parsing, auditing, and extracting data from IFC models using `ifcopenshell`.

---

## Prerequisites:
```bash
pip install ifcopenshell
```

## Included Tools:
1. **`audit_ifc_properties.py`:** Parses any `.ifc` file and generates a breakdown of IFC classes, Psets, and missing fire ratings.
